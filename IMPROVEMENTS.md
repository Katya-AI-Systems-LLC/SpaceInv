## 📁 Новая структура проекта

```
lib/
├── main.dart
├── game_state.dart
├── collision_detection.dart
├── enemy_movement.dart
├── models/
│   ├── power_up.dart          # Модель для power-ups
│   └── game_mode.dart         # Модель режимов игры
├── services/
│   ├── audio_service.dart      # Сервис звука
│   ├── statistics_service.dart # Сервис статистики
│   ├── achievements_service.dart # Сервис достижений
│   ├── leaderboard_service.dart  # Сервис локального лидерборда
│   └── localization_service.dart # Сервис локализации (en/ru)
├── screens/
│   ├── start_menu_screen.dart     # Стартовое меню (режимы, статистика, рекорды, достижения, настройки)
│   ├── game_screen.dart           # Основной экран игры (power-ups, боссы, режимы, анимации)
│   ├── game_over_screen.dart      # Экран конца игры с рекордами и статистикой
│   ├── settings_screen.dart       # Экран настроек звука и информации
│   ├── statistics_screen.dart     # Экран статистики
│   ├── achievements_screen.dart   # Экран достижений
│   └── leaderboard_screen.dart    # Экран локального лидерборда
└── widgets/
    ├── player.dart
    ├── enemy.dart
    └── bullet.dart

tools/
├── create_sprites.py           # Скрипт для создания спрайтов
└── create_placeholder_sprites.md # Документация
```
