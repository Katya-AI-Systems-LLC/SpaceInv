# Background Music

## Required File
- `background.mp3` - Background music for the game

## Notes
- This file is optional - the game will work without it
- If you want to add background music:
  1. Place an MP3 file named `background.mp3` in this directory
  2. The audio service will automatically use it if available
  3. The music will loop during gameplay

## Free Resources
You can find free background music for games at:
- https://freesound.org/
- https://opengameart.org/
- https://incompetech.com/music/royalty-free/

Make sure any music you use is properly licensed for your use case.
