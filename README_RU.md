# Space Invaders - Enhanced Edition

## 🚀 Обзор проекта

Это улучшенная версия классической игры Space Invaders, созданная с использованием Flutter. Игра включает в себя множество современных функций и механик, которые делают её более интересной и динамичной.

## ✨ Основные возможности

### 🎮 Игровые механики
- **Классический геймплей** Space Invaders с улучшенной графикой
- **5 режимов игры**: Classic, Survival, Hardcore, Galactic Run, Boss Rush
- **Динамическая сложность**, адаптирующаяся к навыкам игрока
- **Система комбо** для увеличения очков
- **Боссы** с уникальными паттернами атаки

### 🔫 Продвинутая система оружия
- **6 типов оружия**:
  - Basic Cannon (базовый)
  - Spread Shot (дробовик)
  - Laser Beam (лазер)
  - Plasma Cannon (плазма)
  - Rocket Launcher (ракеты)
  - Wave Gun (волновое оружие)
- **Система энергии** для оружия с регенерацией
- **Визуальные эффекты** для каждого типа оружия

### ⚡ Специальные способности
- **Time Slow** - замедление времени
- **Screen Clear** - очистка экрана
- **Mega Shield** - мега-щит
- **Rapid Fire** - ускоренная стрельба
- **Система перезарядки** с визуальными индикаторами

### 👾 Продвинутые враги
- **8 типов врагов** с уникальными способностями:
  - Sniper (снайпер)
  - Tank (танк)
  - Healer (лекарь)
  - Spawner (спавнер)
  - Phantom (фантом)
  - Morphing (морфер)
  - Shielded (щитовой)
  - Teleporter (телепортер)
- **ИИ врагов** с использованием способностей
- **Визуальные индикаторы** здоровья и щитов

### 🌌 Экологические опасности
- **6 типов опасностей**:
  - Asteroids (астероиды)
  - Space Debris (космический мусор)
  - Black Holes (черные дыры)
  - Solar Flares (солнечные вспышки)
  - Comets (кометы)
  - Nebula (туманности)
- **Динамический спавн** опасностей
- **Стратегические элементы** геймплея

### 💎 Улучшенные бонусы
- **10 типов бонусов**:
  - Multi-Shot (мультивыстрел)
  - Shield (щит)
  - Speed Boost (ускорение)
  - Life Up (дополнительная жизнь)
  - Weapon Upgrade (улучшение оружия)
  - Energy Boost (восстановление энергии)
  - Time Bomb (временная бомба)
  - Magnet (магнит)
  - Drone (дрон)
  - Freeze (заморозка)
- **Взвешенная система** появления бонусов

### 🎨 Визуальные эффекты
- **Экранная тряска** при взрывах
- **Частицы** и визуальные эффекты
- **Эффект замедления времени**
- **Уникальные визуальные эффекты** для каждой способности
- **Анимированные индикаторы** и прогресс-бары

### 🏆 Система достижений
- **Множество достижений** для разблокировки
- **Система очков** и рекордов
- **Таблица лидеров** (локальная и онлайн)
- **Кампания** с уникальными миссиями

## 🎮 Управление

### Клавиатура
- **← →** - движение игрока
- **Пробел** - стрельба
- **Q/E** - переключение оружия
- **1-4** - активация специальных способностей
- **P/ESC** - пауза

### Touch/Мышь
- **Перетаскивание** - движение игрока
- **Тап/Клик** - стрельба

## 🚀 Установка и запуск

### Требования
- Flutter SDK 3.0+
- Dart SDK 2.17+
- Для веб: современный браузер

### Установка
```bash
# Клонирование репозитория
git clone https://github.com/username/space-invaders.git
cd space-invaders

# Установка зависимостей
flutter pub get

# Запуск в браузере
flutter run -d chrome --web-port=8080

# Запуск на Windows
flutter run -d windows

# Запуск на Android
flutter run -d android
```

## 📦 Сборка

### Веб-версия
```bash
flutter build web --web-renderer canvaskit
```

### Windows
```bash
flutter build windows
```

### Android
```bash
flutter build apk --release
flutter build appbundle --release
```
