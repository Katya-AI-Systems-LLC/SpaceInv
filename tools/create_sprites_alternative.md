# Альтернативный способ создания спрайтов

Если Python Pillow не установлен, используйте один из этих способов:

## Способ 1: Установить Pillow

```bash
pip install Pillow
```

Затем запустить:
```bash
python tools/create_sprites.py
```

## Способ 2: Использовать онлайн редактор

1. Откройте https://www.piskelapp.com/
2. Создайте спрайты:
   - **Player**: 50x50, зеленый треугольник (ракета)
   - **Enemy**: 40x40, желтый пришелец
   - **Bullet**: 5x15, циан прямоугольник
3. Экспортируйте как PNG
4. Сохраните в `assets/images/`

## Способ 3: Использовать GIMP / Photoshop

1. Создайте новые изображения нужного размера
2. Нарисуйте спрайты
3. Сохраните как PNG с прозрачным фоном
4. Поместите в `assets/images/`

## Способ 4: Временное решение

Игра работает БЕЗ спрайтов - использует цветные виджеты как fallback.
