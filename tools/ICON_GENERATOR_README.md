# 🎨 Random Icon Generator

Этот скрипт генерирует уникальные рандомные иконки для Space Invaders приложения на всех платформах.

## 📋 Требования

```bash
pip install Pillow
```

## 🚀 Использование

### Сгенерировать новые иконки

```bash
python tools/generate_icons.py
```

### Затем пересобрать приложение

```bash
flutter clean
flutter pub get
flutter run
```

## 🎨 Характеристики генератора

- **Рандомные цветовые палитры**:
  - Neon (Magenta, Cyan, Yellow)
  - Space (Dark Blue, Pink, Light Blue)
  - Retro (Red, Orange, Yellow)
  - Cyberpunk (Dark, Cyan, Magenta)
  - Sunset (Deep Orange, Orange, Amber)

- **Геометрические формы**:
  - Круги
  - Квадраты
  - Треугольники
  - Звезды

- **Эффекты**:
  - Случайный фон
  - Глоу-эффект границы
  - Уникальная компоновка для каждой генерации

## 🔄 Как это работает

1. Генерируется одна базовая иконка (1024x1024) с рандомными формами и цветами
2. Базовая иконка масштабируется до всех необходимых размеров для каждой платформы
3. Иконки сохраняются в правильных директориях для каждой платформы
4. Flutter автоматически использует эти иконки при следующей сборке

## 💡 Советы

- Каждый запуск скрипта создает уникальные иконки
- Для использования конкретного набора иконок, сохраните их до запуска скрипта снова
- Большие размеры (1024x1024) идеальны для сторов приложений
- Маленькие размеры (16x16, 20x20) используются в системе

## 🔧 Настройка

Чтобы изменить параметры генерации, отредактируйте:
- `COLOR_PALETTES` - цветовые палитры
- `num_shapes` - количество формы
- `shape_size` - размеры формы

## ❓ Проблемы

Если получаете ошибку о Pillow:
```bash
pip install --upgrade Pillow
```

Если иконки не обновляются:
```bash
flutter clean
flutter pub get
```
