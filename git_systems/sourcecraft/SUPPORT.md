# Support

## Getting Help

If you have questions about Space Invaders, here are some resources to help you:

1. **Documentation**: Check the [README.md](../README.md) file for basic information about the project.
2. **Issues**: Search through existing [issues](issues) to see if your question has already been answered.
3. **New Issue**: If you can't find an answer, feel free to [open a new issue](issues/new).

## Community Support

For general questions and discussions, you can reach out to the community through:

- [Community Forum](https://community.spaceinvaders.game) - For general discussions and questions
- [Discord Server](https://discord.spaceinvaders.game) - For real-time chat with other users and developers
- [Twitter](https://twitter.com/spaceinvaders) - For announcements and quick updates

## Professional Support

For professional support options, please contact us at [support@spaceinvaders.game](mailto:support@spaceinvaders.game).

## Contributing

If you're interested in contributing to Space Invaders, please read our [Contributing Guide](CONTRIBUTING.md) and [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Issues

When reporting issues, please include:

1. A clear description of the problem
2. Steps to reproduce the issue
3. Expected vs actual behavior
4. Screenshots if applicable
5. Environment information (OS, Flutter version, etc.)

## Feature Requests

We welcome feature requests! Please [open an issue](issues/new) and describe:

1. The feature you'd like to see
2. Why it would be useful
3. Any implementation ideas you might have

## Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
